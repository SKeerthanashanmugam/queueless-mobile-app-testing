# Appium Automation

This is a safe starter framework, not a claim that automation has run against a real build. Obtain an authorized APK, inspect its accessibility identifiers, replace the example locators in `pages/`, configure test credentials as environment variables and execute through Appium.

Automation candidates: valid/invalid login, search, filter, booking smoke and appointment display. Keep payment interruption, visual usability, physical notifications and exploratory checks manual unless a stable test harness is available.
