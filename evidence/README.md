# Evidence Guide

Store only sanitized evidence. Never commit credentials, OTPs, access tokens or real patient data.

Naming convention: `TC-023_android15_pass_01.png` or `BUG-001_android14_actual.png`.

For each failure capture build number, device/OS, timestamp, test-data ID, screenshot/video, relevant sanitized log and API correlation ID where available.

The `screenshots/` folder contains no fabricated evidence. Add files after real execution.
